# 크리스마스 솔로파티 모바일 초대장

사이트 주소: https://kmupium-lab.github.io/mathnight43/

- `index.html`: 이미지·글꼴·포스터가 포함된 모바일 초대장
- `og.jpg`: 초대장 첫 화면과 링크 공유에 함께 쓰는 크리스마스트리 이미지

## 배포

GitHub Pages에서 **Deploy from a branch → main → / (root)**로 설정합니다.
이후 `main`에 변경 사항을 올리면 자동으로 반영됩니다.

## 수정

`index.html`의 제목·행사 안내·초대 문구는 HTML 텍스트로 수정합니다.
스크립트의 `EVENT`에는 지도 링크와 장소 정보가 있습니다.
포스터는 `IMG.poster1`~`IMG.poster3`에 이미지로 포함되어 있어, 문구가 바뀌면 포스터와 `og.jpg`도 함께 갱신해야 합니다.
방문자용 관리자 화면은 없으며, 저장소 파일을 수정해 배포하는 방식입니다.

## 애니메이션

표지를 스크롤하면 확대·이동하며 사라지고 초대 문구가 차례로 나타납니다. 트리 조명과 눈 효과, 식순과 하단 등장 효과를 포함합니다. 화면이 짧으면 내용을 자르지 않는 일반 스크롤 전환을 사용하며, 운영체제의 동작 줄이기 설정에서는 정적으로 표시합니다.

표지 → 초대 문구 → 행사 안내의 두 전환에 같은 페이드를 적용합니다. 눈은 고정된 전체 화면 레이어에서 계속 내리며, 페이지 양옆 바깥 여백과 그림자를 제거했습니다. 동작 줄이기 설정에서는 눈과 전환을 끕니다.

크림색 세로 줄무늬 배경은 이미지 양옆부터 모든 페이지 아래까지 화면 전체에 이어집니다.
