# 크리스마스 솔로파티 초대장

공개 주소: https://kmupium-lab.github.io/mathnight43/

배포 파일은 `index.html`, `og.jpg`, `README.md`입니다. `index.html`에 글꼴, 표지, 줄무늬 SVG 배경과 장소 사진가 포함되어 있어 파일을 직접 열어도 확인할 수 있습니다. GitHub Desktop에서 `main`을 Push하면 GitHub Pages가 갱신됩니다.

## 이번 수정

- 처음 포크한 `1ee14b5`의 고정 화면과 스크롤 진행률 방식을 참고해 HTML, CSS와 애니메이션을 다시 정리했습니다. 이전 수정에서 누적된 CSS 덮어쓰기와 레이아웃 모드 전환 코드는 제거했습니다.
- 제공한 크리스마스트리 이미지를 표지와 OG 이미지에 사용합니다. 배경 줄무늬는 원본 이미지 상단에서 색과 가로 위치를 읽어 만든 SVG이며, 표지와 항상 같은 폭과 중심으로 표시됩니다. 배경을 움직이거나 표지를 확대하지 않아 페이드 중에도 줄무늬 위치가 어긋나지 않습니다.
- 표지 → 초대 문구 → 행사 안내의 페이드, 트리 조명, 모든 페이지의 눈 효과를 유지합니다.
- 모바일 주소창이 접히거나 펼쳐지는 높이 변경에는 레이아웃을 재생성하지 않습니다. 화면 폭이나 방향이 실제로 바뀔 때만 재계산합니다.
- 짧은 화면에서 내용을 자를 정도로 공간이 부족하면 일반 스크롤로 표시합니다. 운영체제의 동작 줄이기 설정도 존중합니다.
- 폰트가 준비되기 전에 먼저 스크롤한 경우 읽던 화면을 갑자기 고정 화면으로 바꾸지 않습니다.

## 검증

2026-11-19, Chrome과 Safari 계열 WebKit 엔진에서 각각 390×844, 375×667, 320×568, 430×932, 1440×900을 확인했습니다. 실물 휴대폰에서 직접 실행한 검사는 아닙니다.

- 첫 페이드 도중 높이를 82px 늘렸다 복원해도 스크롤 위치, 문서 높이, 전환 진행률이 유지됨
- 두 페이드, 역스크롤, 행사 안내 버튼, 식순 표시
- 작은 화면의 본문 전체 가독성, 가로 넘침 없음
- 전체 페이지 눈 효과와 동작 줄이기 설정
- 지도 전환, 장소·초대장 링크 복사
- 장소 사진 탐색·다운로드, 닫은 뒤 스크롤 위치와 버튼 초점 복귀
- 느린 폰트 로딩 전에 읽기 시작한 경우와 JavaScript 없는 읽기 화면
- 이미지 폭과 배경 줄무늬의 폭·중심 위치 일치

## 12월 19일 행사 정보 수정

날짜를 12월 19일로, 입장을 19:00으로 변경했습니다. 시간표는 19:00 입장, 19:10 식사, 19:30 1부, 21:00 2부, 22:00 뒤풀이로 정리했습니다.
표지와 초대 문구 사이 여백은 화면별 기존 값의 1/3로 줄였습니다. 390×844에서 193.75px → 64.58px, 1440×900에서 72.13px → 24.03px이며 Chrome·WebKit에서 확인했습니다.
표지 날짜는 내장 image_gen 편집으로 수정했으며 프롬프트는 작업본의 image-edit-prompt.txt에 기록했습니다.

## 파티장소 미리보기

마지막 카드의 제목과 팝업 제목을 ‘파티장소 미리보기’로 변경했습니다. 카드에는 첫 번째 장소 사진을 표시하며, 팝업에서는 사용자 제공 사진 3장을 업로드 순서로 볼 수 있습니다. 사진은 전체 비율을 유지하고 넘기기·사진 저장을 지원합니다. 초대장 링크 복사와 행사 날짜·시간·페이드·눈 효과는 유지합니다.
Chrome·WebKit에서 390×844, 320×568, 1440×900의 사진 순서, 세로 사진 표시, 탐색, 다운로드, 닫기·다시 열기, 초점·스크롤 위치 복귀를 확인했습니다.

## 오시는 길 약도 교체

사용자 제공 크리스마스 핀이 표시된 역삼역 지도로 기존 이동 순서 그림을 교체했습니다. PNG 원본을 HTML에 그대로 포함하며 지도 전체 비율을 유지합니다. 눌러서 길찾기·앱 선택·약도 다시 보기를 유지하고, 320px 폭에서도 모든 버튼이 표시되도록 맞췄습니다. Chrome·WebKit의 320×568, 390×844, 1440×900에서 확인했습니다.
