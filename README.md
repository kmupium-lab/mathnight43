# 크리스마스 솔로파티 초대장

공개 주소: https://kmupium-lab.github.io/mathnight43/

배포 파일은 `index.html`, `og.jpg`, `README.md`입니다. `index.html`에 글꼴, 표지, 줄무늬 SVG 배경과 장소 사진이 포함되어 있어 파일을 직접 열어도 확인할 수 있습니다. GitHub Desktop에서 `main`을 Push하면 GitHub Pages가 갱신됩니다.

## 이번 수정

- 처음 포크한 `1ee14b5`의 고정 화면과 스크롤 진행률 방식을 참고해 HTML, CSS와 애니메이션을 다시 정리했습니다. 이전 수정에서 누적된 CSS 덮어쓰기와 레이아웃 모드 전환 코드는 제거했습니다.
- 제공한 크리스마스트리 이미지를 표지와 OG 이미지에 사용합니다. 배경 줄무늬는 원본 이미지 상단에서 색과 가로 위치를 읽어 만든 SVG이며, 표지와 항상 같은 폭과 중심으로 표시됩니다. 배경을 움직이거나 표지를 확대하지 않아 페이드 중에도 줄무늬 위치가 어긋나지 않습니다.
- 표지 → 초대 문구 → 행사 안내의 페이드, 트리 조명, 모든 페이지의 눈 효과를 유지합니다.
- 모바일 주소창이 접히거나 펼쳐지는 높이 변경에는 레이아웃을 재생성하지 않습니다. 화면 폭이나 방향이 실제로 바뀔 때만 재계산합니다.
- 짧은 화면에서도 세 화면의 페이드를 유지합니다. 화면보다 긴 내용에는 문서 스크롤 구간을 추가해 끝까지 읽은 후 다음 화면으로 전환합니다. 운영체제의 동작 줄이기 설정에서는 일반 스크롤로 표시합니다.
- 표지를 즉시 독립된 화면으로 설정하고, 폰트가 준비되면 현재 전환 진행률을 유지하며 높이를 다시 측정합니다.

- 첫 페이드 도중 높이를 82px 늘렸다 복원해도 스크롤 위치, 문서 높이, 전환 진행률이 유지됨
- 두 페이드, 역스크롤, 행사 안내 버튼, 식순 표시
- 작은 화면의 본문 전체 가독성, 가로 넘침 없음
- 전체 페이지 눈 효과와 동작 줄이기 설정
- 지도 전환, 장소·초대장 링크 복사
- 장소 사진 탐색·다운로드, 닫은 뒤 스크롤 위치와 버튼 초점 복귀
- 느린 폰트 로딩 전에 읽기 시작한 경우와 JavaScript 없는 읽기 화면
- 이미지 폭과 배경 줄무늬의 폭·중심 위치 일치

Chrome·WebKit의 320×568, 390×844, 1440×900에서 행사 안내의 정확한 문구와 항목 제목 줄바꿈 방지, 가로 넘침, 기존 두 페이드와 눈 효과를 확인했습니다.

## 작은 화면의 페이드 복구

행사 안내가 뷰포트보다 길면 모든 애니메이션을 끄던 높이 조건을 제거했습니다. 화면마다 필요한 읽기 스크롤 길이를 계산해 표지 → 초대 글 → 행사 안내의 두 페이드를 항상 유지합니다. 내용이 긴 경우 해당 화면을 문서 스크롤로 끝까지 읽은 후 다음 화면으로 전환하며, 내부 스크롤 영역은 만들지 않습니다. 폰트 준비 전 첫 스크롤에도 표지가 다른 화면과 섞이지 않게 즉시 화면을 분리하고, 주소창의 높이 변화에는 기존 스크롤 길이를 유지합니다. 현재 글·프로그램·사진은 유지합니다.

Chrome·WebKit에서 320×568, 348×598, 375×600, 375×667, 390×664, 390×844, 430×932, 844×390, 1440×900을 확인했습니다. 모든 크기의 첫 화면 분리, 두 페이드·역스크롤, 각 화면 마지막 문구까지 읽기, 82px 높이 변화 중 위치·진행률·문서 높이 유지, 행사 안내 버튼, 폰트 준비 전 첫 스크롤, 동작 줄이기 설정을 검증했습니다. 실물 휴대폰 검사는 아닙니다.
화면 회전·글꼴 준비 후 재측정은 전체 스크롤 비율 대신 현재 읽기/페이드 구간의 진행률을 보존해 읽던 페이지가 바뀌지 않습니다. 회전 후 읽기 페이지 유지와 아래 지도·사진 갤러리 왕복도 Chrome·WebKit에서 확인했습니다.
